📚 About This Project

このプロジェクトはMNISTデータセットを用いた深層学習デモアプリケーションです。ウェブブラウザからリアルタイムでモデルの訓練が可能です。

✨ Features

  • 🚀 リアルタイムグラフ表示 - 訓練ロスと検証精度を動的に可視化
  • ⚙️ エポック数調整 - ウェブUIからエポック数を自由に変更
  • 🎯 MNISTデータセット - 28×28ピクセルの手書き数字画像
  • 💨 高速訓練 - 全データセットの5%を使用して高速化
  • 📊 詳細な統計 - 訓練ロスと検証精度を追跡
  • ✍️ インタラクティブな推論テスト - 訓練したモデルで手書き数字を認識

🎮 How to Use

  1. ページ上部の「Epochs」欄でエポック数を設定（1～50）
  2. 「Train Model」ボタンをクリック
  3. モデルが自動で訓練され、リアルタイムでグラフが更新
  4. 訓練完了後、上部のグラフで結果を確認
  5. 「✍️ Digit Recognition」セクションで訓練したモデルをテスト
  6. キャンバスに手書き数字を描画して「Predict」をクリック
  7. モデルが認識結果と信頼度を表示します

🏗️ Model Architecture

ニューラルネットワーク構成:

  • 入力層: 784次元（28×28画像フラット化）
  • 隠れ層1: 128ユニット + ReLU + Dropout(0.2)
  • 隠れ層2: 64ユニット + ReLU + Dropout(0.2)
  • 出力層: 10ユニット（0～9の数字分類）

訓練設定: Adam最適化器、クロスエントロピー損失、Learning Rate: 0.001

📈 What to Expect

訓練が進むにつれて、左側のロスグラフが減少し、右側の精度グラフが上昇する様子が見られます。

注意: このデモではデータセット全体の5%のみを使用しているため、完全なモデル性能には到達しません。
